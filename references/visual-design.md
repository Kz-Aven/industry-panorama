# 写实等距资产制作标准

技能默认风格配置为 [industrial-isometric-v1](../config/visual-style.yaml)。以[制造检验参考](../assets/illustrations/production-quality-v2.png)中的写实工业微缩模型为材质和人物比例参考。参考图用于统一画风，单个资产需要单独生成、登记和使用。

## 固定参数

| 项目 | 统一标准 |
| --- | --- |
| 相机 | 正交等距，常用方位角 45°，俯角约 35.264°，水平轴在屏幕上各 30°，竖线保持竖直 |
| 光照 | 画面左上方大面积柔光，所有朝向保持同一画面光向，控制高光，阴影主要落在自身 |
| 材质 | 冷灰哑光粉末喷涂钢、细刷纹不锈钢、透明或烟色玻璃、自然织物、浅暖木。观看缩略图时仍能区分主要材质 |
| 配色 | 深海军蓝、板岩蓝灰、冷灰白和低饱和青绿为主。安全黄和状态灯用在真实功能位置 |
| 尺度 | 以米记录长、宽、高。成人常用高约 1.71 m。控制台、门、桌、椅和机器与该尺度协调 |
| 输出 | 独立透明 RGBA PNG。人体、脚轮、设备支脚和其他支撑端完整可见。轻微材质反射保留在轮廓内，所有视图均无标题、环境底图、字样或无关装饰 |
| 布局 | 采用地面接触中心锚点，放到台面上的资产以实际接触面为 z 原点。底板由场景参数控制面积和厚度 |
| 朝向 | ID 下分别登记 0°、90°、180°、270° 的真实视角。0° 朝屏幕右下，90° 朝左下，180° 朝左上，270° 朝右上。主体的部件、服装和动作在四个方向一致 |

## 生成与审核

每次只生成一个可复用物件的四向图。使用同一参考图和这套相机、光照及材质描述。让 ImageGen 将四个方向按 0°、90°、180°、270° 排成四格，给轮廓留足透明边距。细长设备的正反面、长轴和操作面特别容易画反，剪裁前对照有向视图。

审核单件时检查方向、轮廓、结构、比例与真实透明背景。把不同类别的物件放在同一场景，检查人机比例、桌面物件和支撑关系。整体质感一致后批准登记。场景里的角色、设备位置和桌面物件都可按 ID 独立替换。

研究新行业时，从工作行为清单找素材。先复用通用的角色、家具和物料包装，行业专用设备登记在 `assets/industry/<行业ID>/`，并在相应行业包添加业务同义词和映射。材质、尺度与方向沿用本标准。
